# `@cilla-apps/cilla-web`

Shared browser utilities used across Cilla Mini web apps:

- `phonon-tts` WebAssembly initialization & IndexedDB weight caching
- Persian text normalization & sentence-by-sentence chunking (compatible with `phonon/web/persian.js`)
- Optional Latin-to-Persian transliteration helper for tech/brand terms
- Streaming 24 kHz audio playback queue
